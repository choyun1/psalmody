# Orders of service: the music of each kind of service, in the order it happens.
# The service planner shows these boxes in this order.
#
# Under a service's name, one line per piece of music:
#     key: Label                   (kind)
# kinds:  hymn    = hymn number(s): 390, LEVAS 114, or several: WLP 729, WLP 731
#         anthem  = a hymn or a piece with words; a piece's words are kept in parish/anthems/
#         service = service music: carried on from the last service of this kind,
#                   unless you change it
#         music   = anything else (the default), written Title - Composer (dates)
# more words in the brackets, after a comma:
#         optional       a box that's hidden until you ask for it (the Kyrie, in Lent)
#         bare           listed as just the piece ("Magnificat in B flat - Stanford"),
#                        without "Label:" in front
#         words=NAME     the words that go with it are always the same, from parish/anthems/NAME.txt
#                        (the Magnificat), whatever setting is sung
# A line that isn't music, "spreadsheet: no", keeps this kind of service out of the music schedule spreadsheet.
# A label can say "{hymn|anthem}": it becomes "hymn" or "anthem" by what's sung ("Offertory hymn").
# "lesson" is a kind too: a reading, written  Genesis 3:1-22 | Adam and Eve rebel against God …,
# listed as "The First Lesson: …" (the summary comes from parish/lessons.csv if left out).
# "repeat" lets a piece come any number of times, in any order (the lessons, hymns and carols of
# Lessons and Carols): the planner then shows the service as a list to add to and rearrange.
#
# The planner picks the order named on the Sunday file's service: line, else the one named
# like the day (Palm Sunday, Easter Vigil, Christmas Eve…), else the first one in this file.
# A parish can keep its own copy as parish/services.txt, which then replaces this one.
# There, a column name in [brackets] at the end of a line says which column of an old
# music-schedule spreadsheet that piece was written in, so old plans can be read back.
